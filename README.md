# 🎮 Tienda de Videojuegos MVC

Proyecto educativo para el programa de **Análisis y Desarrollo de Software (SENA)**.

Este repositorio existe para **enseñar**, no solo para funcionar. Cada commit representa
una etapa del desarrollo, pensada para explicarse en clase.

## Objetivo

Demostrar de forma práctica:

- Fundamentos de Back-End: cliente/servidor, HTTP, JSON.
- Algoritmos: validación, búsqueda (lineal y binaria), ordenamiento (burbuja), agregación de datos.
- Arquitectura de software: patrón **MVC** (Modelo - Vista - Controlador).
- Principio SOLID: **Responsabilidad Única (SRP)**, con refactorización antes/después.
- Un patrón de diseño: **Repository**.

## Estado

🚧 En construcción — el proyecto se irá completando por fases. Revisa el historial de commits
para ver la evolución paso a paso.

## Tecnologías

- HTML5, CSS3, JavaScript (Front-End)
- Node.js + Express (Back-End)
- Git y GitHub (control de versiones)

Sin frameworks de Front-End (React/Vue/Angular) y sin base de datos: los datos viven en
`data/videojuegos.json`.
